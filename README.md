# ashfaq099.github.io

Personal academic site of Md Ashfaqur Rahman. Plain HTML, no build step.

## Publish on GitHub Pages

1. Create a **public** repository named exactly `ashfaq099.github.io`.
2. Upload `index.html`, `.nojekyll`, this README, `cv.pdf`, and `assets/photo.jpg`.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. The site goes live at `https://ashfaq099.github.io` within a minute or two.

## Before you publish

- Replace `your.email@example.com` in `index.html` with your real address.
- Add `cv.pdf` (your compiled LaTeX CV) to the repo root.
- Add a headshot at `assets/photo.jpg` (portrait crop, around 600 × 750 px). Without it, initials show.
- Point the SOAP-note project's **Code** button at its own repository.
- Fill in degree years in the Education section.

## Updating

Edit `index.html` directly. New publications go at the top of the Publications section; news items go newest first. Change the "Last updated" line in the footer each time.
